Willow House Budget is a household budget site for one family — Maya, Tom and Leo Willow — for November 2026. It shows the month at a glance, lists every transaction, keeps a budget per category, tracks the bills still due, grows four savings goals, and reports six months of income against spending. Every figure is computed from the same transaction list, so the dashboard, budgets and reports always agree, and every control works: add or delete a transaction, change a budget limit, mark a bill paid, add money to a goal. All data stays in the browser's local storage; the site makes no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. The site is static files under `app/` with no build step.
